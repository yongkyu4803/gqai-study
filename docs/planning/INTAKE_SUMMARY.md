## 2. 시작 질문에 대한 정규화된 답변

### 2.1 만들고 싶은 서비스

강사가 사전에 실습 모듈을 직접 만들고, 학생 개인 또는 그룹에 맞춤형 강의 카드로 배정하며, 학생별 학습·제출·피드백을 관리하는 프라이빗 과외 사이트.

### 2.2 가장 먼저 사용할 사람

- 1차 운영자: 프라이빗 과외를 운영하는 강사 1명
- 1차 최종 사용자: 강사가 직접 등록한 학생
- 학생 규모: 소수 개인 과외에서 여러 그룹까지 확장할 수 있어야 함

### 2.3 현재 문제와 해결 방식

현재 실습과제는 Notion과 같은 문서에 작성할 수 있지만 다음 운영 정보가 분리된다.

- 누구에게 어떤 과제를 배정했는지
- 학생이 내용을 실제로 확인하고 수강했는지
- 어떤 결과물을 언제 제출했는지
- 어떤 피드백을 주고받았는지
- 재제출과 최종 완료 상태가 무엇인지

문서, 메신저, 파일 링크를 함께 사용하면 학생별 이력이 흩어지고 그룹 배정의 반복 작업이 늘어난다. 전용 서비스는 모듈 재사용과 학생별 실행 기록을 한곳에 묶어야 한다.

### 2.4 첫 버전의 핵심 행동

1. 강사가 모듈을 작성·발행하고 학생 또는 그룹에 배정한다.
2. 학생이 배정된 카드를 학습하고 수강 상태 및 결과물을 기록한다.
3. 강사가 학생별 피드백을 남기고 재제출 또는 최종 완료로 처리한다.

## 3. 참고한 모듈 형태

사용자가 제공한 `AI 공부방` Notion 페이지의 과제는 다음 패턴을 가진다.

- 과제 제목과 기준 날짜
- 과제 목적과 배경 설명
- 단계별 실행 지시
- 체크리스트와 주의사항
- 복사해서 사용할 프롬프트 또는 코드 블록
- 외부 강의 및 참고 링크
- 이미지와 PDF 자료
- 제출해야 하는 산출물 설명

따라서 MVP 모듈 편집기는 범용 Notion 복제본이 아니라 위 콘텐츠를 표현할 수 있는 제한된 블록 편집기로 설계한다.

## 4. 확정된 제품 결정

- 초기 강의 11개는 Notion 원문을 변환한 seed로 제공하고, 이후 모듈은 관리자 화면에서 직접 작성한다.
- 모듈 원본은 반복 사용 가능한 템플릿이다.
- 배정은 특정 모듈 버전을 참조한다.
- 그룹은 관리·일괄 배정 수단이며 공동 학습 결과를 만들지 않는다.
- 그룹 배정도 학생별 배정, 진행률, 제출, 피드백을 각각 생성한다.
- 학생 제출은 텍스트, URL, 이미지, 일반 파일을 모두 지원한다.
- 학생 계정은 강사가 생성하고 자가 회원가입은 제공하지 않는다.
- 향후 기능은 실제 동작 없이 내비게이션·라우트·서비스 경계만 준비한다.
